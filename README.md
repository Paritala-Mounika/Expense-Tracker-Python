# Expense-Tracker-Python
A simple Expense Tracker built using Python and Tkinter
## Abstract
The Expense Tracker is a Python-based application developed using the Tkinter library. The main purpose of this project is to help users record and manage their daily expenses efficiently. Users can enter the expense name and amount, view the list of expenses, and calculate the total expenditure. The project provides a simple graphical user interface (GUI), making it easy to use. This application demonstrates the use of Python programming concepts such as lists, functions, loops, event handling, and GUI development.
## Features
-Add Expenses
-Display Expense List
-Calculate Total Expenses
-Simple Graphical User Interface (GUI)
-User-Friendly Design
## Technologies Used
-Python
-Tkinter
